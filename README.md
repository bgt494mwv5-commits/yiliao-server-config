# 易聊公网地址配置
公网 IP 变化后，只修改 [yiliao-server.json](./yiliao-server.json) 中的 `publicIP` 并提交。端口保持 18080、18443、3478，路由器仍转发到原电脑。不要修改 schema、文件名、分支或仓库地址。
Android 190 起的本机版优先使用本地保存的地址；只有连续确认旧地址无法连接，才读取本仓库的 raw 文件。新地址验证可用后保存到本机。旧地址可用时不访问 GitHub；登录错误、权限错误或服务返回错误不会触发换地址。获取失败保留旧地址，失败请求不会自动重发。
本机服务器每分钟检查地址。旧地址不可达、本站服务正常且新地址验证通过后，更新本站端点、STUN 地址和原测试 CA 签发的 IP 证书；更新时相关业务服务会短暂重启。地址有效时不会读取 GitHub。
后台使用 `http://新IP:18080/admin/login`，Web 使用 `https://新IP:18443/`。浏览器原 IP 书签不能自动变成新 IP，请按本文件的新地址打开；Web 仍须信任本机测试 CA。手机升级到支持此配置的版本后，后续换 IP 不用重新打包。
此仓库公开，仅保存服务器公网地址和说明。不要上传密码、Token、签名文件、证书私钥、数据库或用户资料。
